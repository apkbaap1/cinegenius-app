02 · What you need

Three ways to run them.

A

Desktop app: easiest

Download the installer from the repo's Releases page (or the project website) and install it like any app. AppFlowyOpenWhisprCap
B

Docker: for servers and team tools

Install Docker Desktop, then run the project with the Docker Compose file from its README. OpenProjectChatwootCal.diyOpenSEO
C

Run locally from source: for AI tools

Clone the repo and follow its setup steps, usually installing Python or Node.js dependencies. Open HiggsfieldVoiceStudio
03 · How to install any repo

The universal routine

# 1. Get the code
$ git clone https://github.com/OWNER/REPO.git
$ cd REPO
# 2. Server apps: start them with Docker (if the README has a compose file)
$ docker compose up -d
# 3. Then open the address the README gives, e.g. http://localhost:3000
Always follow the README. Every project has its own setup steps, settings and environment variables. The commands above are the common pattern, not exact instructions for every repo.

Before you install

  • Git to clone repos
  • Docker Desktop for server apps
  • Enough disk space and RAM
  • A GPU helps for AI voice and video

Read these first

  • README: setup steps
  • Releases: ready-made installers
  • License: what you can do with it
  • Issues: known problems

08 · Stay safe

Check before you run

Look for recent commits, an active Issues tab and a clear license. Download only from the official repo or website.

Protect your keys

Keep API keys in the project's settings or .env file. Never paste them into public code or screenshots.

Back up your data

Self-hosted means you own the backups. Export or back up your data folders regularly.

Keep it updated

Update from the Releases page, or pull the latest version and restart, to get security fixes.
